## Tab 1 · 壁纸（Browse）

### 职责

- 展示内置 + `files/downloads/` 入库壁纸  
- 搜索 / 排序 / 设置入口  
- 进 `PreviewActivity` → **应用壁纸**（`apply_wallpaper`）  
- 顶栏「未连接」= PC 配对状态（车机上通常恒为未连接）

### 车机实况

| 项 | 结论 | 证据 |
|---|---|---|
| 列表展示 | 可用 | 实车截图：内置 Scene 网格正常 |
| 预览出画 | 可用（mobile mpkg） | Denia/75681 预览 PASS；桌面 TEX 会灰底 |
| **官方「应用壁纸」** | **FAIL / 不可靠** | 75681：弹窗「无法应用 / 可能不支持 Android 动态壁纸」 |
| shell 绑定 WE 组件 | **PASS** | `SetWpUser` → dumpsys user12 = WE；桌面出画 |
| 冷启动自持 | **CB-FAIL 风险高** | 冷启动验收文档：OEM 易抢回 |
| 横屏布局 | 可接受 | 1920 座舱可裁切，非否决 |
| 顶栏「未连接」 | 噪音 | PC 组播在车机无意义，易误导 |

### 需适配 / 优化

| 优先级 | 项 | 建议 |
|---|---|---|
| **P0** | 预览页「应用」 | 拦截/替换为 **shell 绑定** `WEWallpaperService`（与 Motif 同源）；勿依赖系统 Live Wallpaper UI |
| **P0** | 开机自持 | 开机广播 / 壳侧重绑；目标 CB-PASS |
| **P1** | 顶栏连接态 | 隐藏「未连接」或改成「车机模式 / 本地库」 |
| **P1** | 设置页 | 关闭音频响应默认、FPS 档、省电暂停对座舱是否合理，做默认档 |
| **P2** | 分享文件/链接 | 车机无社交场景，可藏 |
| **P2** | 搜索 | 库变大后有用；当前非阻塞 |

**判定：必须适配。** 这是用户「设壁纸」的主路径，官方 Apply 在 HU 上是硬断点。

## Tab 2 · 播放列表（Playlist）

### 职责

- 多壁纸轮换：顺序 / 随机 / 星期 / 时段（`PlaylistSettingsActivity`）  
- 清空、重置时长、设置  

### 车机实况

| 项 | 结论 |
|---|---|
| 与手机产品一致性 | 逻辑在 Java，不依赖 DocumentsUI |
| 座舱使用频率 | **低**：行车中很少手动切播放列表 |
| 与绑定关系 | 播放列表仍依赖 **当前 Live Wallpaper 为 WE**；Apply 断点同样存在 |
| 时段/星期 | 依赖系统时间，车机可用，但价值有限 |

### 需适配 / 优化

| 优先级 | 项 | 建议 |
|---|---|---|
| **P2** | 默认策略 | 可不主推；保留即可 |
| **P2** | 文案/引导 | 避免暗示「连电脑做播放列表」 |
| **P3** | 性能 | 多 Scene 轮换注意 GPU/温控，可限制列表长度或强制低 FPS |

**判定：可暂缓。** 无硬阻塞；先保证 Tab1 单壁纸应用与自持，再考虑轮换。

## Tab 3 · 添加（Import）

### 职责（官方原版）

1. **与计算机配对** → `DiscoverDevicesActivity`（组播 7884 / TCP 7889）  
2. **导入文件** → SAF `OpenMultipleDocuments`（DocumentsUI）  
3. 创意工坊信息（帮助链）

### 车机实况

| 官方入口 | 车机 | 状态 |
|---|---|---|
| 与计算机配对 | 网络隔离 / 场景不友好 | **已改**：文案→扫码导入，跳转车机壳 `we_mode=qr` |
| 导入文件（SAF） | **无 DocumentsUI** → 点了无反应 | **已改行为**：跳转壳 `we_mode=scan`（**文案保持「导入文件」**） |
| 创意工坊信息 | 外链 | 次要 |

### 仍需优化

| 优先级 | 项 | 建议 |
|---|---|---|
| **P0** | 扫描→入库→回壁纸库 | 壳侧「全部入库」后自动回官方 **壁纸** Tab，确认 `downloads/` 可见 |
| **P0** | 多用户 | adb/`emulated/0` 与 user12 库隔离；分享落盘路径已部分覆盖，需实车再验华为分享 |
| **P1** | 批量 VIEW | 官方 `singleTop` 导致批量入库需 `CLEAR_TASK`；可补丁 `onNewIntent` 做真批量 |
| **P1** | 扫码 UX | 现为 URL 列表；可加二维码图 + 推荐 IP |
| **P2** | 隐藏工坊按钮 | 减少外链点击 |

**判定：主路径已适配，体验收口未完成。** 底部「添加」可继续用官方 Tab，逻辑在壳 + 补丁。

## 横切（三 Tab 共用）

| 问题 | 影响 Tab | 动作 |
|---|---|---|
| 官方 Apply 被 OEM 拒 | 1（核心）、2 | 统一 shell Apply |
| 冷启动组件丢失 | 1、2 | 开机重绑 |
| 无 DocumentsUI | 3 | 已扫库替代 |
| PC 配对文案/状态 | 1 顶栏、3 | 弱化/改写 |
| 横屏触控热区 | 全部 | 底部 Tab 在 HU 可用；注意与系统底栏重叠（已见 1920 布局可点） |
| 官方 so 性能/温控 | 1 预览与桌面 | FPS/质量档 P1 |

## 优先级路线图（建议）

```
P0  壁纸 Tab · 应用 = shell 绑定（预览 ✓ 不再弹失败）
P0  壁纸 Tab · 开机重绑（CB-PASS）
P0  添加 Tab · 入库后回壁纸库可见（闭环）
P1  壁纸 Tab · 顶栏「车机模式」/ 藏未连接
P1  添加 Tab · 扫码二维码 + 批量入库稳
P2  播放列表 · 默认不推；可选限长
P2  设置 · 座舱默认 FPS/静音
```

## 一句话

| Tab | 要不要动 |
|---|---|
| **壁纸** | **要** — 设壁纸与开机是车机生死线 |
| **播放列表** | **可后做** — 非阻塞，价值低 |
| **添加** | **已动主路径，要收口** — 扫码/扫库已接，入库闭环与 Apply 串联还差最后一公里 |

完整闭环目标：

> **添加（扫/传）→ 壁纸库可见 → 预览 → shell 应用 → 冷启动仍在。**
