# 官方 Wallpaper Engine Android — 车机 30 分钟摸底清单

> **目的**：判断官方 Companion（2.8.8）在阿维塔/华为 HU 上 **能否安装 / 预览 / 设为座舱壁纸**，并输出明确结论表。  
> **不是**：量产方案。摸底后仍大概率需要 Motif 绑定层（见下文判定）。  
> **默认车机**：`LD249H019625` · **user 12** · 安装器 `com.huawei.appinstaller.car`（与 Motif 相同，禁止裸 `adb install`）。

---

## 0. 准备（2 分钟）

| 项 | 要求 |
|---|---|
| 线材/ADB | `adb devices` 见 `LD249H019625` device |
| 官方 APK | `sandbox/we-android/wallpaper-engine.apk`（或官网直链） |
| 脚本 | `scripts/we-android-car-probe.sh` |
| 对照 | 可选：先记下当前 Motif 是否在绑 `dumpsys wallpaper` |

```bash
# 一键摸底（安装 + 启动 + dumpsys + 尝试 shell 绑定 + 写报告）
./scripts/we-android-car-probe.sh LD249H019625

# 仅探测不安装
./scripts/we-android-car-probe.sh LD249H019625 --skip-install

# 指定 APK
./scripts/we-android-car-probe.sh LD249H019625 /path/to/wallpaper-engine.apk
```

报告默认：`audit-we-android-<时间戳>/` 与 `docs/previews/` 旁的 audit 目录（脚本打印路径）。

## 2. 时间盒流程（约 30 分钟）

### T+0～5 · 安装（自动化优先）

脚本会：

1. `pm disable-user` 系统 `com.android.packageinstaller`（user0/12，与 Motif 相同）  
2. `pm install -r -d -g -t -i com.huawei.appinstaller.car --user 12`  
3. 可选 user0  
4. 恢复 PackageInstaller  
5. 授权常用权限（存储/通知等，失败可忽略）

**人工勾选**

| # | 检查 | 通过 | 失败时 |
|---|---|---|---|
| I1 | `pm path --user 12 io.wallpaperengine.weclient` 有路径 | ☐ | 看 install 日志；确认 ABI arm |
| I2 | `dumpsys package` versionName=2.8.8 | ☐ | 装错包/旧包 |
| I3 | 无 `INSTALL_FAILED_*` | ☐ | 记录完整错误码 |

### T+5～12 · 启动与 UI

```bash
adb -s SER shell am start --user 12 \
  -n io.wallpaperengine.weclient/.BrowseActivity
```

| # | 检查 | 通过 | 失败时 |
|---|---|---|---|
| U1 | 进程存活 `pidof io.wallpaperengine.weclient` | ☐ | logcat 崩栈 |
| U2 | 主界面列表可见（含内置壁纸） | ☐ | 黑屏/闪退 → 记 log |
| U3 | 能点开某一内置项进入预览 | ☐ | 权限/存储 |
| U4 | **预览画面有动画**（Scene 或视频） | ☐ | GPU/GLES/内存 |
| U5 | 横屏座舱布局可接受（可裁切） | ☐ | 仅 UX，非否决 |

**现场**：拍 1 张主列表 + 1 张预览（可选 `adb exec-out screencap`）。

### T+12～18 · 系统「设为壁纸」（官方路径）

在预览页按官方流程尝试 **设为动态壁纸**（勾选/应用）。

| # | 检查 | 通过 | 失败时 |
|---|---|---|---|
| S1 | 出现系统壁纸确认 UI | ☐ | **车机无入口** → 记「需 shell 绑定」 |
| S2 | 确认后桌面/座舱背景变化 | ☐ | 仍是 OEM 壁纸 |
| S3 | `dumpsys wallpaper` 中 user 12 的 `mWallpaperComponent` 含 `weclient` | ☐ | 绑失败 |

```bash
adb -s SER shell dumpsys wallpaper | grep -E 'User |mWallpaperComponent|mName' | head -40
```

### T+18～24 · Shell 强制绑定（Motif 同款能力探测）

若设备上有 `setwp_user.dex`（Motif 脚本用）：

```bash
# 脚本会自动尝试；手工：
adb -s SER shell "export CLASSPATH=/data/local/tmp/setwp_user.dex; \
  app_process /system/bin SetWpUser \
  io.wallpaperengine.weclient \
  io.wallpaperengine.weclient.WEWallpaperService 12"
adb -s SER shell dumpsys wallpaper | grep -E 'User |mWallpaperComponent' | head -20
```

| # | 检查 | 通过 | 失败时 |
|---|---|---|---|
| B1 | shell 绑定无 SecurityException | ☐ | 权限/签名/OEM |
| B2 | user12 component = WEWallpaperService | ☐ | 绑定被拒 |
| B3 | **座舱实际画面**变为 WE 内容 | ☐ | 假绑定/合成层不是该 surface |
| B4 | 等 30s 无自动切回 OEM | ☐ | 主题服务抢占 |

### T+24～28 · 稳定性快扫

| # | 检查 | 通过 | 备注 |
|---|---|---|---|
| R1 | 回桌面/切应用再回，壁纸仍在 | ☐ | |
| R2 | 亮灭屏一次 | ☐ | |
| R3 | logcat 无连续 native crash | ☐ | `libscenejni` |
| R4 | 温控/掉帧主观可接受 | ☐ | Scene 重负载 |

### T+28～30 · 填结论表（必须）

见 §3。报告目录里会有 `RESULT.md` 模板，人工补「目视」行。

## 3. 结论判定表（输出物）

复制填写，或改脚本生成的 `RESULT.md`：

| 判定项 | 结果 (Y/N/P) | 证据 |
|---|---|---|
| 能安装到 user12 | | I1–I3 |
| App 能启动 | | U1–U2 |
| 内置壁纸预览出画 | | U3–U4 |
| 官方 UI 能设壁纸 | | S1–S3 |
| shell 能绑定 WE 组件 | | B1–B2 |
| 座舱真实显示 WE | | B3 |
| 短时不被 OEM 抢回 | | B4, R1 |

**总判定（四选一）**

| 代号 | 含义 | 后续 |
|---|---|---|
| **A. 开箱可用** | 官方 UI 设壁纸成功且座舱显示稳定 | 仍建议监控开机抢占；量产可评估双 APK |
| **B. 引擎可用、绑定要适配** | 预览 OK，仅 shell/OEM 绑定能上桌 | **主流预期**；WE 独立产品 + Motif 绑定层 |
| **C. 仅能跑 UI** | 安装启动 OK，预览黑/崩 | GPU/内存不足；Scene 慎入，视频路径另测 |
| **D. 装不上/起不来** | install 或启动失败 | ABI/策略/签名；放弃直装官方包 |

**华为车机是否还要适配？**

| 总判定 | 还要适配吗 |
|---|---|
| A | 弱适配：开机保活、横屏、导入路径 |
| B | **要**：绑定 + 多用户 + 抗抢占（Motif 已有能力迁移） |
| C/D | **要**，且引擎层也要降级或换方案 |

## 5. 与 Motif 的关系（摸底后）

| 摸底结果 | 建议 |
|---|---|
| B（最常见） | 官方/WE-Car 负责渲染；**Motif 或 shared-car-bind 负责 setWallpaperComponent** |
| A | 仍保留 Motif 视频回退；开机脚本巡检 component |
| C/D | 量产继续 Motif 视频引擎；WE 仅作研发参考 |

**不要**在未完成 §3 判定前，把 `libscenejni` 并进 Motif 量产包。

---

## 6. 安全注意

- 摸底会 **短暂 disable** 系统 PackageInstaller（与 Motif 安装相同），脚本 `trap` 会 re-enable；若中断请手动：

```bash
adb -s LD249H019625 shell pm enable --user 12 com.android.packageinstaller
adb -s LD249H019625 shell pm enable --user 0 com.android.packageinstaller
```

- 绑定 WE 会 **替换当前 user12 壁纸**；测完可重新跑 `set-motif-wallpaper-shell.sh` 恢复 Motif。
